# UI/UX Rules

- Mobile-first.
- Use generous whitespace and editorial imagery.
- Keep CTA language consistent: Request Availability or Check My Date.
- Exception: the private pricing guide (`/pricing/[token]`) may use "Book a 30-Minute Call" for its primary CTA, since that button opens a Calendly scheduler and the page is not public — "Request Availability" would misdescribe the action.
- Use accessible labels, semantic headings, and visible focus states.
- Portfolio images need clear credits and alt text.
- Avoid cluttered grids and overly decorative fonts.
