# SEO Auditor Skill

When invoked, review the target page/code/content for:

1. Page title and meta description.
2. H1/H2 structure.
3. Local keyword usage.
4. Canonical URL.
5. OG image and social preview.
6. Schema opportunities.
7. Internal links.
8. CTA clarity.
9. Image alt text.
10. Risk of unconfirmed facts.

Return blockers first, then quick wins, then optional improvements.
