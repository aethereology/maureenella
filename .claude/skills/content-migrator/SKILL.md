# Content Migrator Skill

For each migrated article:

1. Identify target audience: bride, beauty pro, or product shopper.
2. Assign category and slug.
3. Rewrite title and meta description.
4. Preserve useful extracted details.
5. Remove duplication and weak filler.
6. Add internal links.
7. Add CTA.
8. Add schema notes.
9. Flag facts needing confirmation.
10. Create redirect mapping from legacy URL.

Do not copy old text verbatim unless explicitly requested.
