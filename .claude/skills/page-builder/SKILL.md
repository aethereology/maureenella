# Page Builder Skill

When building a page:

1. Read relevant docs and seed data.
2. Define page goal and primary CTA.
3. Create semantic structure.
4. Use reusable components.
5. Add metadata.
6. Add schema where appropriate.
7. Add accessible form/links/buttons.
8. Avoid unconfirmed pricing/policies.
9. Test responsive behavior.
10. Update task files.
