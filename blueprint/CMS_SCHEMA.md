# CMS Schema Blueprint

Use this if moving from local JSON/MDX to a CMS.

## Collections

- Pages
- Services
- Portfolio
- Testimonials
- FAQs
- Journal Posts
- Products/Favorites
- Lead Magnets
- Redirects
- Service Areas

## Required editorial fields

Every public content record should include:

- Title
- Slug
- SEO title
- SEO description
- OG image
- Canonical override if needed
- Status: draft/review/published
- Last updated
- Internal notes

## Permissions

Only confirmed content should be published. Drafts can contain extracted legacy data, but publish workflow must require review.
