# SEO Strategy

## SEO goals

1. Protect and improve legacy organic traffic.
2. Rank for local bridal hair and makeup searches.
3. Turn blog content into structured SEO clusters.
4. Use real weddings for local and venue-based SEO.
5. Create search-driven education content later.
6. Support AI/search answer visibility through clear structured content.

## Technical SEO requirements

- Clean route structure.
- Unique title and meta description per page.
- Canonical URLs.
- XML sitemap.
- Robots.txt.
- Image alt text.
- Internal links between related posts/pages.
- Structured data.
- Redirects from old URLs.
- Fast mobile performance.

## Content migration rules

- Do not copy low-quality old text verbatim if it is thin or repetitive.
- Merge duplicate topics.
- Preserve useful original dates if migrating with update notes.
- Add vendor/location details to real weddings.
- Add internal CTAs to services and inquiry pages.
- Add image credits.
- Redirect old URL to new canonical article.

## Structured data plan

- Organization schema sitewide.
- LocalBusiness/BeautySalon schema on home, bridal, contact, and location pages once NAP is confirmed.
- Service schema for services.
- FAQPage schema on FAQ pages only when visible FAQ content is present.
- Article schema for journal posts.
- BreadcrumbList schema for all nested pages.

## Local SEO actions

- Align website NAP with Google Business Profile exactly.
- Add service area language naturally.
- Add embedded map only if it helps and does not hurt performance.
- Add location-specific landing pages after Phase 1.
- Request reviews after weddings.
- Use real wedding posts as local proof.
