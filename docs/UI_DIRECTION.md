# UI Direction

## Desired feeling

Premium bridal editorial, warm founder-led confidence, calm wedding morning, soft sophistication.

## Design adjectives

- Editorial
- Warm
- Romantic
- Clean
- Modern
- Calm
- Feminine but not childish
- Luxe but approachable
- Organized
- Sunlit

## Avoid

- Generic salon website feel
- Heavy black/gold glam cliche
- Cluttered Wix-style sections
- Too many fonts
- Overuse of stock icons
- Product/affiliate clutter on bridal pages
- Aggressive countdown or scarcity banners

## Color direction

Use soft neutrals with gentle contrast:

- Warm ivory / cream
- Soft beige / oatmeal
- Muted taupe
- Warm brown text
- Dusty rose accent
- Soft champagne accent
- Optional deep espresso for contrast

## Typography direction

- Elegant serif for headlines.
- Clean sans-serif for body and UI.
- Avoid overly decorative script except possibly tiny accent use.

## Layout direction

- Mobile-first.
- Large editorial imagery.
- Generous whitespace.
- Split sections with image + copy.
- Sticky mobile CTA for Request Availability on bridal pages.
- Portfolio cards with minimal overlays and proper credits.
- Accordion FAQ.
- Resource cards for prep guides.

## Component priorities

- Hero with image/video and CTA.
- Review strip.
- Service cards.
- Process steps.
- Portfolio grid.
- Testimonial cards.
- FAQ accordion.
- Blog cards.
- Inquiry form.
- Lead magnet callout.
- Affiliate/product card with disclosure.

## Imagery

Prioritize real Maureen/client images over stock.

Image types:

- Bride getting ready.
- Closeups of hair details.
- Makeup closeups.
- Bride + bridal party.
- Venue/editorial portraits.
- Maureen working.
- Salon suite.
- Flat lays with prep products sparingly.

## Accessibility

- Text contrast must be readable.
- Buttons need clear labels.
- Form inputs need labels and error messages.
- Do not rely only on color.
- All images need intentional alt text.
- Carousels should not auto-advance without control.
